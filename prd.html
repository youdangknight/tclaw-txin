团队项目协作能力需求文档

在个人项目能力基础上，新增团队项目类型，支持多人成员、节点化任务编排、任务下发与资料分级授权。

适用范围
项目模块（个人 / 团队项目）

1背景与目标

1.1 背景

现有项目为个人工作空间，承载个人任务、资料与 AI 对话产出，不支持多人协同。团队场景下，工作需要按项目节点拆解、明确负责人和截止时间、按文件夹控制资料可见范围，因此在同一套项目体系内新增团队项目类型。

1.2 目标

编号目标
G1个人项目与团队项目共用同一套项目模型与详情页结构，个人项目可升级为团队项目
G2提供三步建项向导：基础信息 → 项目节点 → 任务配置，发布项目后任务自动下发给负责人
G3支持项目成员与角色管理、节点化任务流转、资料文件夹与分级权限
G4全产品命名口径一致：与 AI 的会话统一称「对话」，工作执行单元统一称「任务」

1.3 V1 不做

不纳入 V1 的能力说明
AI 工作情况汇总卡 / 重新点检管理者视角的整体进度、风险项目点检本期不做
工作首页改版不新增问候区、五张统计卡、归档项目入口，工作首页保持现有形态
项目管理列表改版不新增行式列表视图与状态筛选，项目列表保持现有形态
任务辅助 Agent 字段不为任务指定 AI 助手，后续版本评估
任务新留言红点提醒不做未读红点机制
项目归档与恢复项目级归档、归档库本期不做
全局导航调整左侧导航保持「新建任务 / 任务记录 / 定时任务 / 项目 / AI 资产库」不变
升级逆向个人项目升级为团队项目后，V1 不支持降回个人项目
其他跨组织外部协作、甘特图与资源排期、多级子任务、多人实时在线文档

2核心概念

维度个人项目团队项目
成员仅创建人本人负责人（创建人）+ 项目成员，可设角色
任务个人任务，无节点要求挂载在项目节点下，有负责人、截止时间、归档要求，发布即下发
资料平铺文件列表，无权限设置文件夹组织，文件夹/文件可独立设置可见与编辑范围
详情页 Tab对话 / 任务 / 资料对话 / 任务 / 资料 / 成员
创建方式新建项目时默认类型建项时选择团队类型，或由个人项目升级

2.1 命名铁律

对话：用户与 AI 的一次会话（消息流）。开启新会话一律称「新对话」，对话场景内禁止使用「任务」表述。
任务：需执行完成的工作单元，有负责人、截止时间与状态。创建、分配、下发、完成、审核的对象均为任务。
废弃词：「事项」一词在全部页面、字段、按钮、通知中停止使用，统一为「任务」（外部系统导入模板的原始列名除外）。

3关键规则

3.1 个人项目升级规则

规则内容
数据不迁移升级仅变更项目类型，原项目 ID、任务、资料、产出物、对话历史全部保留，不复制、不删除
历史不改写升级前的对话内容与项目记忆不因升级而改变
私有不默认开放个人私有对话与个人记忆不随升级自动对成员开放，仅开放用户明确共享的内容
升级后引导升级完成后引导补充：项目成员、项目节点、任务负责人指派
不可逆升级为团队项目后 V1 不支持降回个人项目，操作前需二次确认

3.2 任务下发与状态规则

规则内容
发布即下发团队项目完成向导后，任务按负责人自动出现在其「我的任务」列表中
状态展示口径对外统一展示三种状态：已完成 / 待完成 / 已延期；其中待完成聚合待处理、执行中、待审核三种内部状态
延期自动判定当前时间超过截止时间且任务未完成，自动标记为已延期，无需人工操作
任务归属每个任务必属一个项目节点；删除节点时，其下任务移入「未分组」，禁止级联删除
截止时间任务截止时间不得晚于项目计划结束时间

3.3 资料与权限规则

规则内容
文件夹团队项目内置「默认文件夹」（不可删除），成员可自建文件夹；删除自建文件夹时，其中文件移入默认文件夹，不复制、不删除
权限粒度每个文件夹、每个文件均可独立设置：全员可见可编辑 / 部分成员可见可编辑；未单独设置时继承上级默认
角色权限负责人：全部管理权限；可编辑：查看、上传、下载与编辑；仅查看：只能浏览
负责人兜底项目负责人始终可见全部资料，不受部分可见范围限制
上下文隔离成员不可见的资料，不得进入其项目对话的 AI 引用上下文
个人项目不显示文件夹侧栏与权限入口，资料平铺展示

3.4 对话上下文规则

  • 项目内发起的新对话自动携带：项目说明 · 项目资料 · 项目记忆
  • 项目记忆由任务完成等关键节点自动沉淀，AI 在本项目任务执行中默认参考
  • 对话强归属唯一项目；任务引用对话内容时只引用、不复制，迁移不改变历史

4功能需求

4.1 新建项目向导

个人项目只需填写基础名称即可创建；团队项目按三步完成配置，步骤条可回退查看已填内容。

第一步 · 基础信息

字段必填规则
项目名称必填1–30 字
所属业务必填文本填写，1–20 字
负责人必填默认为创建人
项目级别选填S 级（公司重点）/ A 级（部门重点）/ B 级（常规项目）/ C 级（一般任务）
计划开始时间必填日期选择
计划结束时间必填不得早于计划开始时间
项目简介选填不超过 120 字
项目成员团队必填至少 1 名成员；默认角色「可编辑」，可调整为「仅查看」
外接知识库选填可绑定外部知识库，绑定后项目对话可引用其中内容
项目文件选填点击或拖拽上传；支持 Word / PPT / PDF / Excel / 图片；单文件不超过 20MB，最多 20 个；上传后作为项目初始资料

第二步 · 项目节点

需求规则
节点配置默认提供节点 1–4 可重命名；支持添加节点、删除节点、上移 / 下移调整顺序
节点模板支持「上传本地模板」「使用项目模板」两种方式一键生成节点结构
校验节点名称非空，同一项目内节点名称不可重复

第三步 · 任务配置

列项必填规则
节点任务名称必填按节点分页签编排，逐节点检查
任务负责人必填从项目成员中选择
任务描述选填文本说明任务要求与交付标准
截止时间必填不得晚于项目计划结束时间
归档要求必填需要归档文件 / 需要归档链接 / 无需归档
操作—删除任务；列表底部提供「+ 添加任务」
发布动作：团队项目第三步主按钮为「发布项目并下发任务」。存在必填项缺失时阻断发布，并定位到首个缺失项。

4.2 项目详情页

Tab个人团队能力说明
对话有有项目共享对话与个人私有对话分区展示；输入区发起的新对话自动携带项目上下文
任务有有顶部三张状态卡片（已完成 / 待完成 / 已延期）带数量统计，点击筛选；下方为任务卡片列表；团队任务显示所属节点与负责人
资料有有个人：文件平铺。团队：左侧文件夹列表（含文件数、部分权限锁标），右侧当前文件夹权限信息条 + 文件列表 + 上传文档；支持文件夹新建、重命名入口与删除（默认文件夹除外）
成员无有成员列表与角色（负责人 / 可编辑 / 仅查看），支持添加成员、调整角色
  • 任务卡片信息：任务名称与状态标签、任务描述、所属节点与截止时间、「查看详情」与「去完成」
  • 项目设置包含：项目简介编辑、外接知识库绑定、项目记忆查看、升级为团队项目（仅个人项目显示）、删除项目

4.3 资料权限设置

入口 / 操作结果
文件夹「设置权限」弹窗选择全员可见可编辑 / 部分可见可编辑；选择部分时勾选成员，负责人始终默认在可见范围内且不可取消
单文件权限设置文件操作菜单中可对单个文件单独授权，规则与文件夹一致；部分可见时文件名后显示锁标
保存后权限条实时更新权限类型、可见人数与成员名单；权限随项目持久保存

5对象定义

对象产品定义V1 规则
个人项目单人的 AI 工作空间仅创建人可见，可升级为团队项目（不可逆）
团队项目多成员按节点协同的项目包含负责人、成员、节点、任务与资料权限
项目节点团队项目的阶段划分有序、可由模板生成，是任务的挂载点，不可级联删除任务
任务有负责人与截止时间的执行单元三态展示，发布即下发，超期自动标记延期
对话用户与 AI 的会话自动携带项目上下文，强归属唯一项目
项目资料项目内文件团队按文件夹组织并设权限；支持文件与链接两种归档要求
项目记忆项目级 AI 长期上下文由关键节点自动沉淀，成员范围内可用
外接知识库项目绑定的外部知识源可绑定、解绑，作为对话引用来源

6异常与边界

场景表现兜底行为
文件超限上传单文件超过 20MB 或总数超过 20 个拦截并提示具体限制，已选文件保留
发布时必填项缺失任务名称、负责人、截止时间、归档要求存在空值阻断发布，定位到首个缺失项
移除名下有任务的成员该成员仍有未完成任务需先将其名下未完成任务转派给其他成员，否则不可移除
无权限访问文件夹成员不在部分可见名单内文件夹与文件在列表中完全不可见，且不进入其 AI 对话上下文
项目无任务进度统计分母为 0进度显示 0%，不出现异常数值
删除含文件的文件夹自建文件夹下存在文件二次确认后删除文件夹，文件全部移入默认文件夹，不删除文件
升级团队项目个人项目存在私有对话与个人记忆默认不开放，二次确认升级且不可逆

7验收用例

编号场景验收结果
1新建个人项目填写名称即可创建；无节点与成员配置步骤；详情页不显示「成员」Tab
2新建团队项目完整流程三步顺序推进、可回退；必填缺失时阻断并定位；发布后任务出现在各负责人「我的任务」中
3文件上传边界第 21 个文件被拦截并提示「最多 20 个」；超过 20MB 的文件被拦截
4个人项目升级升级后任务、资料、产出物、对话数量零变化；出现成员、节点补充引导；无降回入口
5文件夹部分可见范围外成员看不到该文件夹及文件，其对话中 AI 不引用其中内容；负责人始终可见
6删除自建文件夹二次确认后文件夹消失，文件全部出现在默认文件夹且可正常打开
7任务自动延期超过截止时间未完成的任务自动归入「已延期」状态卡片统计
8移除成员名下存在未完成任务时无法移除，完成转派后可移除
9命名一致性全部页面、按钮、字段、提示中无「事项」字样（外部模板原始列名除外）；对话场景内无「任务」误用
10单文件授权对单个文件设置部分可见后，文件显示锁标，范围外成员在文件夹内看不到该文件

8评审重点

01「所属业务」字段口径
本期按自由文本必填设计，是否需要改为业务字典下拉（选项来源与维护方需明确）。
02任务下发后的修改权限
任务下发给负责人后，创建人与负责人分别可修改哪些字段（截止时间、负责人、归档要求），修改后是否需要通知相关成员。
03成员移除与任务转派
「必须先转派才可移除」的兜底规则是否符合实际管理习惯，是否允许创建人在移除弹窗中直接批量转派。
